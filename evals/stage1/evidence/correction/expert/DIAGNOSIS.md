Foundation sortedKeys at Expert :230 and transport serialization preserves that alphabetical shape. All four saved rejected answers emit text first then update:keep. ## Minimum bounded repair recommendation

- Version the contract v4. Use a nested schema union with three exact alternatives: replace + string text, keep + null text, withdraw + null text; initial request allows only replace. Use nonempty constraint where supported, retain current explicit trimmed-text validation. Keep all original decoding/rejection behavior and no retries/repair/substitute. Preserve plan → publicReason → selectedCard ordering; schema union should enforce validity regardless of text/update ordering. Verify provider compatibility through public serialized request and actual response, not by assuming JSON Schema support.
- Replace `Current trick: .` with an affirmative authoritative phase: e.g. “South leads the next trick” or “North plays third in this trick; South C3 and West C4 have already played; East follows North.” Derive from snapshot/rules only, no strategic ranking.
- Give concise **legal current choices** from the same Engine set already used in selectedCard enum. Prefer this to retransmitting both hands, consumed-card inventories, all plans/reasons or full history. At a new lead these legal choices necessarily equal the remaining acting hand; document that consequence openly. Reprinting a full acting-hand inventory every turn is harder to reconcile with #36's no-default-remaining-hands rule and adds less targeted information; do not present it as required missing context.
- Initial holdings may use explicit card tokens (`DA DK` rather than `D AK`) once, while preserving suit grouping/seat labels and authorized perspective. This targets role/rank binding, but correct source was already explicit; do not claim it guarantees quality.
- Add one concise positive sentence directing a concrete conditional route based on visible winners/establishment/timing/entries and deriving the current reason/card from that route. Preserve plain English natural plans, one player, no deterministic semantic strategy validator and no repeated defect-specific prohibitions. Do not duplicate effective plan each turn by default.
