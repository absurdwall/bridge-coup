# Bundled-runtime first-use evidence — 2026-10-02

## Package and environment

- Local build: Bridge Coup **1.0.0 Beta 1**, build **10001**,
  `Bridge-Coup-v1.0.0-beta.1-arm64.dmg`, 109,424,079 bytes, SHA-256
  `6d3a3e456890aa3866e7eab06747c99d8eeea04b7ca41d0a207c91a31504150c`.
- Host: macOS **27.0.1** (26A434), Apple Silicon `arm64`. The tested host is
  newer than the supported macOS 14 minimum. The DMG was built locally and
  did not have browser-download quarantine.
- Runtime: official standalone **codex-cli 0.156.1**, pinned archive and
  source notices documented in `Release/codex-runtime.md`.

`Scripts/build-macos-dmg.sh` completed, then its `verify-macos-dmg.sh` gate
passed from a read-only mounted image. That gate checked release metadata,
Applications shortcut, executable permissions, all shipped Mach-O files as
arm64 with compatible minimum OS, individual and outer ad hoc signatures,
Codex LICENSE/NOTICE, `codex --version`, an actual app-server `initialize`
and signed-out `account/read` with a fresh `CODEX_HOME`, and a complete-deal
DDS solve. `swift test --filter CodexRuntimeDiscoveryTests` passed **7/7**,
including candidate fallback and executable fixture handshakes.

The DMG was also mounted, copied with `ditto` into an isolated
`/tmp/bridge-coup-firstuse.*/Applications`, ejected, and the copied app
signature and its bundled Codex app-server handshake verified. The GUI copy
launched with `PATH=/usr/bin:/bin` and an isolated `CFFIXED_USER_HOME`;
Application Support and Codex Home were created under that temporary home.
The window showed **Codex codex-cli 0.156.1 · 需要 ChatGPT 登录** when the
per-process runtime preference pointed to the bundled file. With a deliberately
missing per-process manual candidate, discovery fell back to the bundled
`Contents/Resources/codex`, and the expanded connection panel showed the
browser login instructions and **连接 ChatGPT** action. These checks started
with an empty bridge draft and did not exercise preservation after failure.

## Acceptance still open

This was not a clean macOS user. `CFFIXED_USER_HOME`, even combined with
`__CFPREFERENCES_AVOID_DAEMON=1`, did not hide this account's existing
`bridgeTeacher.codexExecutablePath` preference, so the unmodified launch
chose the installed ChatGPT runtime 0.159.2 before the bundled candidate.
The per-process override above tested the bundled path without changing or
deleting the user's preference. No browser login or real teaching turn was
completed from the isolated profile, and the local DMG did not exercise a
download quarantine or security override. A clean macOS 14+ Apple Silicon
user/profile remains required for release acceptance; this ticket must not be
marked complete based on package checks alone.
