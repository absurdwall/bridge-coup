# Bridge Coup 2.0 的连续辅导与首发内容范围

2026-10-04，在 Spec 1.4 的 grill 中确认：2.0 的完整连续牌局验收围绕一个选定的决策控制者进行。Expert 在合法视角下持续建议、保留或修订计划，其他座位的行动可以由用户或外部牌局事实输入。即使需要人工逐张录入，也可构成从起点到结束的完整验收；这避免把 Expert 的交付范围扩展为必须自动控制整桌的对局系统。全桌自动托管和专门的盲打练习 UI 均不是 2.0 发布阻塞项，现有全牌教学工作台保留。

中途且历史不完整的求助是正常入口。系统根据已知材料提供有用分析，受缺失信息影响的部分明确限定为条件建议、需要补充输入或不支持；没有定义所需输入的计算不运行，也不补造历史。严格连续牌局的验收则使用从起点完整跟踪的材料，两类入口保留不同的质量要求。

首发采用基础 CCBA 约定，并配备足以验证真实流程的基础知识、评测和学习材料。体系细化、系统化书籍或在线资料整理、更丰富的专家裁定题库与学习内容可留到 2.0.1 或 2.1。内容规模可以渐进扩充，已声明的视角隔离、证据语义和实际材料覆盖范围仍需如实呈现；基础内容不构成已证明广泛专家棋力的结论。

本记录是对 Spec 1.4 发布范围的澄清，供后续正式 spec 同步，尚不代表实现或验收完成。最小发布质量门槛仍在本轮访谈中确认。
