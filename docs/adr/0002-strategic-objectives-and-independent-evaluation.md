# 战略目标与计算证据、评测裁判分别确定

2026-10-04，在 Spec 1.4 的 grill 中确认：计分背景、正式战略目标和计算分析指标分别表达。用户只指定 IMP 时，最终判断仍遵循 IMP 桥牌策略；Engine 可提供带假设限定的成约比例、原始得分及定约结果分布，但不能因为某指标容易计算，就将其替换为用户的真正目标。用户明确改为只追求成约机会时，这是正式目标变化，需要新的请求与 session。这个取舍保留 Codex 的战略判断职责，也避免计算正确却优化了错误目标。

专家评测以有出处的可信专家材料和人工裁定相结合。每题的裁定记录包含来源、可接受行动或计划、严重错误、理由、适用假设以及争议或可信程度。合理替代方案可以并存；有争议时通过第二来源、外部高手或人工复核处理，未解决的争议题不作为硬性发布门槛。DDS 提供计算证据，LLM 可辅助发现评价规则矛盾，均不担任单明手战略质量的最终裁判。产品负责人批准裁定流程与结果，不被假定为每道复杂题目的唯一专家。

这是评测材料逐步扩充时遵守的质量原则，不要求 2.0 首发就具备完整专家题库。首发基础内容范围见 ADR 0001。
