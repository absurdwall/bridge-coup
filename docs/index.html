The workspace

One hand, several ways to learn.

Start with a contract and the cards you know. Bridge Coup keeps confirmed information and open questions distinct as you explore the play.

01

Build the deal

Enter the contract, opening lead, and visible cards. Import a screenshot and review its editable recognition candidates before using them.

02

Ask about the play

Request a declarer plan or ask about a key decision. Teaching uses the information confirmed for that decision point and requires your own connected AI account.

03

Return to the review

Save reviews and screenshots locally. When a complete deal is available, use separate double-dummy verification as an after-the-fact check.

Your first session

Install and start carefully.

  1. 1

    Download and copy

    Download the versioned DMG from this page, open it, and drag Bridge Coup into Applications. Eject the DMG, then launch the copy in Applications rather than the mounted installer.

  2. 2

    Allow the first launch if macOS blocks it

    This beta is ad hoc signed and not Apple notarized. If macOS blocks it, attempt to open the app, then go to System Settings → Privacy & Security and select Open Anyway for Bridge Coup. Follow the confirmation prompt. Managed-device policies may prevent an override; ask your administrator in that case.

  3. 3

    Connect and review

    Codex is included in the app. Open 连接状态 in the model area. If it says 需要 ChatGPT 登录, click 连接 ChatGPT, complete browser login with your own account, return to Bridge Coup, and click 检查连接. Choose an available model and thinking effort, enter the bridge information visible at the decision point, and request a teaching plan. If setup fails, use the retry controls; your entered bridge work is preserved.
