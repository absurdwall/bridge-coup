# 03: A 版牌桌原位键盘编辑

**What to build:** 用户在 A 版四向牌桌中直接点击某家某花色的牌点行并用键盘修正，修改进入真实复盘流程，替代下方重复的手牌表单。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 浅色双栏保持不变；牌桌北上南下、西左东右，四个独立座位卡与桌心不重叠。每家按 ♠♥♦♣ 四行显示紧凑牌点，不绘制实体扑克牌。
- [ ] 点击行后原位键盘编辑，支持 AKJ83 与 10 等规范牌点，Enter 提交有效值，Escape 取消；移开焦点取消未提交编辑。
- [ ] 非法牌点、重复已知牌和不可能的牌数给出有用提示，失败不写入确认状态；无效 Enter 保持编辑以供修正。
- [ ] 空白表示未知，明确的横线表示已确认空门，附近有简短提示；这一区别贯穿会话、请求和重新打开，不只表现为不同文字。
- [ ] 采用上下文适当的牌数校验，不把残局强行补成每家 13 张；未知牌不补造，决策时隐藏信息边界不放宽。
- [ ] 有效修改触发现有版本与旧分析失效机制；生成与保存使用新值，迟到响应不能回写旧状态。
- [ ] 移除重复的下方四家手牌输入表单，保留庄家、首攻和补充事实等其他背景入口；不做逐张牌点按钮或拖放。
- [ ] 独立于定约新控件完成编辑路径；牌桌中心可先呈现现有定约入口，最终组合在整体验收确认。
- [ ] 在工作流边界覆盖提交/取消、校验、未知/空门、版本和保存恢复，并实际操作 Mac 应用的键盘焦点与编辑。
