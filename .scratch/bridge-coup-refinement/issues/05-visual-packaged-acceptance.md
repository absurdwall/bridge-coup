# 05: 整体视觉精修与实际 Mac 验收

**What to build:** 用户在统一的 A 工作台中使用模型设置、直接定约选择、原位牌面编辑与 Bridge Coup 品牌，并在实际 Mac 应用完成一条可继续保存和复盘的完整路径。

**Blocked by:** 01: 模型与 effort 选择、保存偏好并用于真实请求; 02: 定约表格直接点选并接入当前复盘; 03: A 版牌桌原位键盘编辑; 04: Bridge Coup 名称、选定图标与独立字标落地

**Status:** ready-for-agent

- [ ] 汇合前四票结果，保持 A 的浅色左右布局与四向独立座位卡；统一字号、间距、对比度、控件状态和品牌资源，不重新探索整体设计。
- [ ] 正常 Mac 窗口中牌面、桌心、定约表格和长讲解可读；优先连续页面滚动，避免拥挤的左侧嵌套滚动；关键入口不被遮挡。
- [ ] 完整走通模型/effort 选择、一次直接定约选择、原位牌点修正、真实教学和追问；确认实际请求使用用户选项。
- [ ] 综合检查校验失败、未知/空门、配置回退、旧分析失效与迟到响应；修正后的信息传入真实复盘和必要的求解核验，不泄漏隐藏牌。
- [ ] 保存、退出并重新打开旧复盘和本轮产生的复盘，确认偏好、修正牌面、来源与过期状态正确；改名不影响数据连续性。
- [ ] 从实际打包 app 检查 Finder/Dock 名称图标、界面独立字标及资源完整性；不以静态原型代替。
- [ ] 分别记录确定性测试、运行时模型能力与真实请求证据、实际 Mac 交互和视觉验收结果；列出尚未通过项。
- [ ] 完成针对本轮改动的 code-review 和必要修复，不顺带扩展教学能力或做无关重构。
