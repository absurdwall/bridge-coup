# 03: 围绕同一副牌追问与修正

**What to build:** 用户在同一复盘中追问教学理由、补充信息或修改牌面，系统依据新的决策时信息继续讨论，并明确标记旧分析已过期。

**Blocked by:** 01：在 Mac 中获得第一份真实做庄计划

**Status:** complete

- [x] 右侧支持围绕当前做庄计划发送追问，真实模型回答保留必要的牌局上下文。
- [x] 补充已知事实与提出假设有区别；条件讨论不得自动把假设写成已确认牌面。
- [x] 牌面、分析视角或时点发生影响结论的修正时，旧计划与依赖它的分析标为过期；用户可以重新生成。
- [x] 每次请求与其信息版本关联；旧请求迟到时不覆盖新状态，重试不静默产生重复有效答案。
- [x] 修正后的追问不把历史回答中已经无效的事实作为当前事实继续发送；必要时重建干净的教学上下文。
- [x] 在追问、信息修正与会话重建中保持隐藏信息隔离，未获得依据时不擅自补全未知牌。
- [x] 请求中断或失败后保留问题、已确认材料与既有对话，允许重试。
- [x] 在主要复盘流程边界检查追问、修改、过期与迟到响应，再以真实模型演示一次追问和一次修改后的重新分析。

Evidence: [follow-up and correction demo](../evidence/03-follow-up-corrections-demo.md)
