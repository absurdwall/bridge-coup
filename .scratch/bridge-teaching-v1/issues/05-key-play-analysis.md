# 05: 分析关键出牌节点

**What to build:** 用户选择“分析这一步”，描述关键出牌节点、可见手牌与必要历史，获得具体备选出牌的比较和当时信息下的理由。

**Blocked by:** 01：在 Mac 中获得第一份真实做庄计划

**Status:** ready-for-agent

- [ ] 工作台提供关键出牌分析模式，与整体做庄计划区别清楚，并使用同一份已确认材料。
- [ ] 允许确认分析时点、剩余可见手牌、轮到谁行动及当前墩/相关历史；缺口影响判断时请求补充，不猜测未给出的出牌过程。
- [ ] 围绕当前可选动作解释推荐和有意义的替代路线，而非重复整副牌的泛泛建议。
- [ ] 解释依赖本局具体牌张、交通、读牌与 IMP 目标；基础技巧如忍让在本局重要时说明其实际目的。
- [ ] 分布推断和概率说明写清假设与依据；未经计算不得声称给出已验证的精确成功率。
- [ ] 没有 DDS 时可独立提供明确标记的教学推理，不声称已经验证具体墩数；未来核验可作为分开的证据展示。
- [ ] 模式切换和分析时点改变后不复用不适用的旧结论；当时未知的手牌和未来出牌不得进入教学请求。
- [ ] 通过工作流检查时点变化、缺失历史、非法候选与知识边界，并实际演示一次真实关键出牌讲解。

## Notes

不依赖持续追问或 DDS 就可以验证本票的单次节点分析；完整系统验收再检查它与其余功能的组合。
