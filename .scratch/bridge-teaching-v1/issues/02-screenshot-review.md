# 02: 从截图识别、纠错到生成计划

**What to build:** 用户导入牌局截图，查看原图与可编辑识别结果，纠正漏牌或错牌，再从确认后的信息生成做庄计划；部分截图也能进入教学流程。

**Blocked by:** 01：在 Mac 中获得第一份真实做庄计划

**Status:** in-progress

- [x] 在 A 工作台导入本地截图并查看原图，真实识别服务返回可编辑牌面和已识别的相关上下文；未识别的信息不被补造成事实。
- [x] 用户能够补回遗漏的 A、修正花色或牌点；受控测试确认后续请求使用修正值，而非原始识别文本。
- [x] 区分材料本身未提供的信息与可见但不清晰/有歧义的识别；未知字段会保持未知，计划提示关键缺口并给出条件路线。
- [x] 按当前可见座位检查重复牌和单手超过 13 张；不要求补足每家 13 张牌。
- [x] 即使截图包含四手牌，做庄计划和关键出牌分析也只接收牌手勾选并确认的座位；识别与教学使用独立会话。
- [x] 更换截图、确认或修改牌面后，旧分析失效；识别失败或迟到结果不会覆盖用户的新输入。
- [ ] 受控测试已覆盖漏 A、错牌、未知信息、矛盾牌面与失败恢复；真实截图尚未完成“牌手校正后生成计划”，需要牌手确认所选图片的决策时点和可见信息。
- [x] 记录了 4 张真实图片的识别结果与差异；模拟响应通过之外，实际图片接入也已验证。

## Notes

本票不承诺从一张截图重建未提供的叫牌或完整出牌历史，不要求批量导入。
