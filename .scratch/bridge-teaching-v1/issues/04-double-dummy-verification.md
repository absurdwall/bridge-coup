# 04: 核验完整牌面的双明手结果

**What to build:** 用户在同一工作台为已确认的完整牌面或完整残局运行 DDS，比较当前合法出牌的双明手结果，并清楚看到核验成立的条件与适用范围。

**Blocked by:** 01：在 Mac 中获得第一份真实做庄计划

**Status:** done

- [x] 在 Mac 上集成并实际运行 DDS，记录使用版本、构建/分发要求与适用许可证；提供在应用内可触发的完整路径。
- [x] 支持手动确认四家剩余手牌、将牌、当前墩领出者、本墩已出牌以及求解需要的上下文。
- [x] 只对满足求解条件且合法的局面发起求解；缺失或矛盾材料显示具体原因，仍允许不完全信息教学。
- [x] 展示当前合法出牌对应的实际求解结果，正确处理等价牌、行牌方、部分已出墩与结果所表示的剩余墩数。
- [x] 只有庄家、定约及已获墩数等信息齐全时才换算定约超宕；明确区分剩余可得墩数和全副总墩数。
- [x] 完整牌面与求解结果位于明确的事后核验视图，不进入决策时教学的请求或历史上下文；核验后返回教学仍保持隔离。
- [x] 未核验、输入不足、计算失败、已验证与因修正而过期的结果有明确区分；失败时不展示猜测数字。
- [x] 用独立已知结果的完整牌例和小残局检查精确结果，包括部分已出墩和行牌方解释；实际应用内演示至少一次真实求解。

实现与运行证据见[双明手核验记录](../evidence/04-double-dummy-demo.md)。

## Notes

DDS 可以接受手动确认的完整局面，因此不依赖截图识别。不扩展成单明手概率引擎、全功能牌局播放器或体系叫牌教学。
