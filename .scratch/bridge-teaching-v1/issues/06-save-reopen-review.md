# 06: 保存并继续一份复盘

**What to build:** 用户将含截图、修正牌面、决策上下文和教学对话的复盘保存到本地，关闭应用后重新打开，继续查看和追问。

**Blocked by:** 02：从截图识别、纠错到生成计划；03：围绕同一副牌追问与修正

**Status:** ready-for-agent

- [ ] 提供简单的本地保存与重新打开入口，不引入云账号、同步或多人共享。
- [ ] 保存并恢复原始截图、识别/修正后的信息、分析视角与时点、教学对话和其对应的信息版本。
- [ ] 重新打开后仍能区分已确认信息、未知内容、假设与过期结果，不把历史输出当作当前已核验事实。
- [ ] 恢复后能继续真实追问，教学上下文仍以当时可得信息构建，不把本地存储中的完整隐藏牌一并发送。
- [ ] 当前已存在的分析模式与结果保留其类型、来源和版本；后续加入的关键出牌与求解结果不得因保存而丢失核验/过期状态。
- [ ] 保存失败或读取失败给出明确提示，并保留当前会话；写入失败不破坏先前可打开的复盘。
- [ ] 通过复盘流程入口验证保存/恢复等价的用户可见状态、过期标记和失败恢复，不测试具体存储实现内部步骤。
- [ ] 在实际 Mac 应用里导入并修正一次牌面，产生对话、保存、退出、重新打开并继续追问。

## Notes

依赖截图与持续追问，因为要保存的是这条完整复盘路径。无需等待 DDS 或关键出牌模块才能交付；它们的最终保存兼容性在整体验收中检查。
