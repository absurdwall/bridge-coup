# Bridge Coup 自主推演 UI 原型

Status: prototype direction accepted / 本轮原型方向已确认；已完成用户要求的少量宽度微调，供原会话继续 spec。2026-10-02。

本原型使用 prototype skill 的 UI 分支。比较问题：在既有四家围桌中，将桌心用于当前墩后，叫牌应留在角落、折叠为入口，还是移到桌下？三个布局使用同一条页面路线，通过 `?variant=A/B/C` 切换。A/B/C **仅为本轮局部布局编号**，不替换或重开上一轮已接受的 B 牌桌方向。

## 打开与运行

从项目根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 [布局 A](http://127.0.0.1:8766/.scratch/bridge-coup-play-workspace/prototype/index.html?variant=A)。也可直接双击本目录 `index.html`，无依赖、不需要构建。运行时需保留相对于项目根目录的路径，以复用 `AppResources` 的现有品牌图片。

- A：已确认的角落叫牌小表，可展开／收起。
- B：桌边折叠入口，打开独立浮层查看叫牌。
- C：桌下叫牌摘要，展开为四列记录。

底部箭头或键盘左右键切换，URL 保留布局编号。输入框聚焦时不截获左右键。切换布局保留当前牌局，关闭叫牌展开状态；刷新恢复示例，不保存数据。

## 建议演示路径

1. 默认完整四手，但教学只勾选北／西。点击“开始自主推演”，打开“逐牌结果”。北家每张合法牌直接显示 `=`、`−1`、`+1` 等模拟标签。
2. 北 ♠A → 东 ♠4 → 南 ♠J → 西 ♠Q。各家都由用户点击，东／南／西须跟黑桃；其他牌禁用。已出牌离开各家手牌，并进入桌心。
3. 四张后停留当前墩。点击“收起本墩 · 候选”，NS 增至 1 墩，北家继续首引。可撤销、重做、重走；均为未确认的候选设计。
4. 关闭逐牌结果，合法牌仍可点，但牌上不再有数值。比较 A/B/C 的叫牌位置。
5. 打开“原始四手定约表”。行 ♠♥♦♣NT，列北南东西，单元格完整定约或 `—`。表格基于原始手牌版本，出牌和收墩不改变它。
6. “编辑原始四手”中点击“北♠A ↔ 南♠J”并保存。推演清空，原始版本递增，原定约表失效。再次打开会要求重新载入**模拟**结果；并未调用求解器。
7. 点击“只有两手示例”。东／南显示未知，推演、逐牌结果与定约表禁用；“生成做庄计划 · 演示”仍返回教学输入边界回执。教学可见勾选与推演资格始终独立。

## 回答范围与待选择

已可操作地观察：四家点牌与中央当前墩的衔接；各家轮到时直接显示合法牌结果；两个不同信息边界（教学可见与完整四手）；固定原始定约表的查看／关闭／失效；三种叫牌展示位置。

用户于 2026-10-02 选择本轮 A 叫牌小表，认为整体与想象差别不大。反馈：不必把每张牌做成独立牌片，各家牌区可以稍微紧凑些。已据此去掉逐牌边框与背景，并根据用户提供的现有 app 截图再次收紧：先对齐现有原生界面的 136 px 宽度，再按用户最终“可以再宽一丢丢”的反馈放到 144 px；关闭结果时牌点按字符实际宽度连续排列（如 AKQJ10），取消固定 18 px 牌点占位与牌间间隔；开启结果时仅对当前合法牌保留标签必需的最小宽度。合法牌仍可逐张点选，数值仍直接标在牌点下方。B/C 留作原型历史参考，不再作为待选方向。

用户随后确认当前紧凑牌区适合小牌桌，要求再宽一点点，并在发现“先开始，再点牌”的入口后表示“可以可以，这么着，嗯，可以”。原型方向及显式开始入口已确认，最终牌区为 144 px，牌点仍连续排列。已改清楚开始前的提示。

四张后手动收墩及撤销／重做／重走继续按当前原型展示为候选：用户没有单独回答先前的收墩方式选择卡，不能把整体认可记成这些细节全部逐项确认。原会话可在 spec 中区分已确认方向与建议默认值。尚无最终 spec，也未发布 GitHub issue。交接见 `REVIEW-HANDOFF.md`。

## 边界与来源

- 原型专用 HTML/CSS/JS，状态仅在内存，不读写保存记录、不联网分析。
- 所有逐牌结果与独立定约表为固定／按阶段轮换的假数值，**不具有桥牌求解依据**，不能用于打法判断。当前示例为 5♥，因此超墩标签上限为 +2。
- 本地实现跟牌、行动轮转、将牌赢墩记账，仅用于演示交互；不实现真实 DDS、Runtime、OCR 或教学内容生成。
- 模型与连接只保留现有轻量入口和示意浮层。具体 Runtime 搜索与真实模型 effort 目录待产品实施时处理。
- 四家位置、品牌素材、配色与双栏宿主参考当前 `BridgeTeacherMacApp.swift`，叫牌结构参考 `AuctionTableView.swift` 与 2026-09-27 Issue #4 验收记录。旧 A 截图仅辅助对照宿主配色，未替代当前已接受 B 方向。历史独立原型 HTML 未在当前 checkout 找到。
