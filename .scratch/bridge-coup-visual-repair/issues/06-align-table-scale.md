# 06: 校准 app 牌桌与 A 原型的尺寸差异

**What to build:** 缩小 Mac app 中牌桌相对认可 A 原型明显偏大的视觉差异，同时保持牌点、花色、座位卡和定约的可读性。

**Blocked by:** None

**Status:** open

**Priority:** P2

- [ ] 在同一 synthetic deal、相近内容视口下，对照实际打包 app 与固定版本的 A 原型，记录牌桌宽高和占工作区比例。
- [ ] 调整后四家与定约仍清楚可辨、彼此不重叠；花色颜色及座位顺序保持正确。
- [ ] 在至少两个常见窗口宽度下复核比例与可读性，不将原型截图像素尺寸当成硬编码目标。
- [ ] 保存不含真实复盘数据的两侧对照图与实际打包验收记录。
